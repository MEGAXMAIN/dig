Make Mermaid editable.

Dig turns Mermaid flowcharts into native, movable shapes, connectors, labels, and phase containers on a ClickUp Whiteboard.

Install once

Open this page in the same browser as ClickUp

The bookmark belongs to one browser profile. If ClickUp is in Chrome, open this page in that same Chrome profile—not inside the Codex preview browser. Dig is now self-contained so ClickUp cannot block an external loader.

Preparing the self-contained bookmark…
If dragging does not work
  1. Create any normal bookmark in the browser where you use ClickUp.
  2. Edit that bookmark and name it Dig.
  3. Select Copy bookmark code above and paste it into the bookmark's URL or Address field.
  4. Save it, open a ClickUp Whiteboard, then click the saved Dig bookmark.

Use Dig

Prepare Mermaid syntaxGenerate it from a transcript, a workflow summary, or open an existing .mermaid file.

Open the target ClickUp WhiteboardUse the same browser and profile where you installed the Dig bookmark.

Click the saved Dig bookmarkDig runs inside the currently active ClickUp tab. Paste the Mermaid source, preview it, and drag phase headers if needed.

Inject editable shapesIf your browser blocks automatic injection, Dig leaves the native-shape payload on your clipboard—click the canvas and press ⌘V or Ctrl+V.

Important: If clicking Dig opens this installer page, the bookmark was saved as a normal web link. Delete it and reinstall it using Copy bookmark code. Dig uses ClickUp Whiteboard’s clipboard compatibility rather than an official Whiteboard API, so test on a spare board before a customer session.
